# Ngày 19: Thiết lập danh sách bỏ qua .gitignore

Khi phát triển một dự án, các tệp mới có thể thường xuyên xuất hiện trong working directory (chẳng hạn như các tệp tạm thời hoặc tệp bộ nhớ đệm do các công cụ phát triển như Visual Studio tạo ra). Nhiều tệp trong số này không cần được đưa vào quản lý phiên bản và nên bị loại trừ. Chúng ta gọi đây là "danh sách bỏ qua".

## Hiểu .gitignore

Tệp `.gitignore` chỉ định các tệp untracked có chủ ý mà Git nên bỏ qua. Trong Git, tệp `.gitignore` được sử dụng để định nghĩa "danh sách bỏ qua". Mục đích chính là loại trừ các tệp không cần được thêm vào quản lý phiên bản. Các tệp hoặc đường dẫn (có thể bao gồm ký tự đại diện) được liệt kê trong tệp này sẽ không xuất hiện trong kết quả của `git status`, và tất nhiên sẽ không được thêm vào khi thực thi `git add`.

Tuy nhiên, điều này chỉ áp dụng cho `Untracked files`. Các tệp đã được Git theo dõi (`Staged files`) không bị ảnh hưởng bởi tệp `.gitignore`.

## Tạo .gitignore thông qua GitHub

Nếu bạn đã từng tạo một dự án trên GitHub, bạn có thể đã sử dụng tính năng này. Khi tạo một repository mới, bạn có thể chọn một danh sách bỏ qua được định nghĩa sẵn mà GitHub giúp bạn thiết lập. Danh sách bỏ qua này thực ra chỉ là một tệp có tên `.gitignore`, được đặt trong thư mục gốc của dự án theo mặc định.

Bạn có thể chọn từ nhiều mẫu khác nhau như:
- Node
- Python
- Java
- C#
- Visual Studio
- Và nhiều mẫu khác

## Tạo .gitignore theo cách thủ công

Đơn giản chỉ cần tạo một tệp có tên `.gitignore` trong thư mục gốc của repository của bạn:

```
# On Windows
echo node_modules/ > .gitignore

# On Linux/Mac
echo "node_modules/" > .gitignore
```

Hoặc tạo nó theo cách thủ công bằng một trình soạn thảo văn bản.

## Các mẫu cơ bản

### Bỏ qua các tệp cụ thể

```
config.local.js
secrets.txt
```

### Bỏ qua các tệp có phần mở rộng cụ thể

```
*.log
*.tmp
*.cache
```

### Bỏ qua các thư mục

```
node_modules/
dist/
build/
```

Lưu ý dấu gạch chéo ở cuối để chỉ ra một thư mục.

### Bỏ qua các tệp trong bất kỳ thư mục nào

```
# Ignore all .log files in any directory
**/*.log
```

## Các mẫu nâng cao

### Phủ định (Ngoại lệ)

Sử dụng `!` để tạo ngoại lệ:

```
# Ignore all .log files
*.log

# But don't ignore important.log
!important.log
```

### Chỉ bỏ qua các tệp trong thư mục cụ thể

```
# Ignore test.txt only in root directory
/test.txt

# Ignore test.txt in any subdirectory, but not root
*/test.txt
```

### Nhiều phần mở rộng

```
# Ignore multiple file types
*.{jpg,png,gif}
```

## Các mẫu .gitignore phổ biến

### Dự án Node.js

```
node_modules/
npm-debug.log
.env
.DS_Store
dist/
build/
```

### Dự án Python

```
__pycache__/
*.py[cod]
*$py.class
.venv/
venv/
*.egg-info/
.pytest_cache/
```

### Dự án Java

```
*.class
*.jar
*.war
target/
.gradle/
build/
```

### Dự án .NET

```
bin/
obj/
*.user
*.suo
packages/
.vs/
```

## .gitignore toàn cục (Global)

Đối với các mẫu bạn muốn bỏ qua trên tất cả các repository:

```
git config --global core.excludesfile ~/.gitignore_global
```

Sau đó tạo `~/.gitignore_global` với các mẫu của bạn.

## Bỏ qua các tệp đã được theo dõi

Nếu bạn vô tình commit các tệp đáng lẽ nên bị bỏ qua:

```
# Remove from Git but keep the file
git rm --cached filename

# Remove directory from Git but keep it
git rm -r --cached directory/
```

Sau đó thêm mẫu vào `.gitignore` và commit.

## Xem các tệp bị bỏ qua

Để xem những tệp nào đang bị bỏ qua:

```
git status --ignored
```

## Kiểm tra lý do một tệp bị bỏ qua

Để xem mẫu nào đang khiến một tệp bị bỏ qua:

```
git check-ignore -v filename
```

## Các tệp .gitignore mẫu

GitHub cung cấp các tệp .gitignore mẫu cho nhiều ngôn ngữ và framework khác nhau:

* https://github.com/github/gitignore

## Chú thích trong .gitignore

Sử dụng `#` cho chú thích:

```
# This is a comment
*.log  # Inline comment
```

## Thực hành tốt nhất

1. **Commit .gitignore sớm**: Thêm nó ngay từ đầu dự án của bạn
2. **Cụ thể**: Tránh các mẫu quá rộng
3. **Ghi lại lý do**: Sử dụng chú thích để giải thích các mẫu không rõ ràng
4. **Giữ nó có tổ chức**: Nhóm các mẫu liên quan lại với nhau
5. **Sử dụng mẫu có sẵn**: Bắt đầu với các mẫu dành riêng cho ngôn ngữ
6. **Biến thể cục bộ**: Sử dụng `.git/info/exclude` cho các mẫu cá nhân

## .gitignore trong thư mục con

Bạn có thể có các tệp `.gitignore` trong các thư mục con. Các mẫu có tính tương đối so với vị trí của tệp `.gitignore`.

## Tóm tắt hôm nay

Tệp `.gitignore` là thiết yếu để giữ repository của bạn sạch sẽ và tránh vô tình commit các tệp không thuộc về quản lý phiên bản. Hiểu cú pháp mẫu và các thực hành tốt nhất sẽ giúp bạn duy trì một repository sạch sẽ, chuyên nghiệp.

Hãy để tôi sắp xếp lại các lệnh và tham số Git đã học hôm nay:

* git rm --cached
* git rm -r --cached
* git status --ignored
* git check-ignore
* git config core.excludesfile
