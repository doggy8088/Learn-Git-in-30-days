# Ngày 14: Các tùy chọn cấu hình Git for Windows

Sử dụng các công cụ dòng lệnh Git for Windows chắc chắn hiệu quả hơn thao tác thông qua các công cụ GUI. Lý do là bạn có thể tự động hóa nhiều tác vụ quản lý phiên bản lặp đi lặp lại thông qua lệnh, hoặc biến các quy trình vận hành tiêu chuẩn (SOP) phức tạp thành các thao tác lệnh đơn giản. Bài viết này sẽ chia sẻ một số mẹo sử dụng các công cụ dòng lệnh Git for Windows.

## Về các tùy chọn cấu hình của công cụ dòng lệnh Git

Trong các công cụ dòng lệnh Git, có nhiều "tùy chọn" có thể được thiết lập, giống như khi sử dụng các công cụ GUI chúng ta thường có [Tools] -> [Preferences] để tinh chỉnh một số hành vi khi các lệnh được thực thi. Phổ biến nhất, tất nhiên, là khi bạn lần đầu sử dụng Git for Windows, bạn phải thiết lập các tùy chọn `user.name` và `user.email`. Nếu chưa thiết lập hai tùy chọn này, bạn thậm chí không có quyền thực thi `git commit`.

Để liệt kê tất cả các tùy chọn hiện đang được thiết lập trong các công cụ Git for Windows, bạn có thể dùng lệnh `git config --list`.

**Lưu ý**: Vì hầu hết các bài viết về Git trên internet giới thiệu cách thiết lập môi trường Linux hoặc Mac, bài viết của tôi sẽ tập trung vào cấu hình trên nền tảng Windows. Tuy nhiên, ngoại trừ đường dẫn lưu trữ khác nhau, cách sử dụng các lệnh thực ra là giống nhau.

Nếu bạn muốn kiểm tra xem có những "tùy chọn" nào, bạn có thể thực thi `git help config` tại dấu nhắc lệnh để hiển thị tài liệu đầy đủ hoặc truy cập [Trang hướng dẫn git-config(1)](https://www.kernel.org/pub/software/scm/git/docs/git-config.html).

## Hiểu các cấp độ cấu hình của Git

Git có ba cấp độ cấu hình:

1. **Cấp độ hệ thống (System level)** (`--system`): Áp dụng cho tất cả người dùng trên hệ thống
   * Vị trí: `C:\Program Files\Git\etc\gitconfig`
   * **Quan trọng đối với Windows**: Khi UAC được bật, các thiết lập có thể bị chuyển hướng tới `%LOCALAPPDATA%\VirtualStore\Program Files\Git\etc\gitconfig`
   * **Khuyến nghị**: Luôn chạy Command Prompt với quyền Administrator khi thiết lập các tùy chọn cấp độ hệ thống
   
2. **Cấp độ toàn cục (Global level)** (`--global`): Áp dụng cho người dùng hiện tại
   * Vị trí: `C:\Users\[username]\.gitconfig` hoặc `%USERPROFILE%\.gitconfig`
   * Thường được dùng cho `user.name`, `user.email` và các tùy chọn cá nhân
   
3. **Cấp độ cục bộ (Local level)** (`--local`): Chỉ áp dụng cho repository hiện tại
   * Vị trí: `.git\config` trong repository
   * Được tạo tự động khi bạn khởi tạo hoặc clone một repository

Cấu hình ở cấp độ thấp hơn sẽ ghi đè cấu hình ở cấp độ cao hơn (local > global > system).

## Xem cấu hình

Để xem tất cả các cấu hình hiện tại:

```
git config --list
```

Để xem cấu hình từ một cấp độ cụ thể:

```
git config --global --list
git config --local --list
git config --system --list
```

## Thiết lập danh tính người dùng

Cấu hình cơ bản nhất là thiết lập tên người dùng và email của bạn:

```
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

Các thiết lập này được sử dụng trong mọi commit bạn thực hiện.

## Cấu hình trình soạn thảo mặc định

Thiết lập trình soạn thảo văn bản ưa thích của bạn cho các thông điệp commit:

```
git config --global core.editor "code --wait"  # VS Code
git config --global core.editor "notepad"      # Notepad
git config --global core.editor "vim"          # Vim
```

## Cấu hình ký tự kết thúc dòng (Line Ending)

Điều này quan trọng đối với phát triển đa nền tảng:

```
# Windows (convert LF to CRLF on checkout, CRLF to LF on commit)
git config --global core.autocrlf true

# Linux/Mac (convert CRLF to LF on commit, no conversion on checkout)
git config --global core.autocrlf input

# No conversion
git config --global core.autocrlf false
```

### Quan trọng: UAC của Windows và VirtualStore

Trên Windows Vista và các phiên bản sau này khi User Account Control (UAC) được bật, có một điểm quan trọng cần cân nhắc khi thiết lập cấu hình cấp độ hệ thống:

**Vấn đề**: Công nghệ VirtualStore của Windows chuyển hướng việc ghi tệp khi các tiến trình không có quyền quản trị cố gắng ghi vào các thư mục hệ thống. Điều này có nghĩa là:
- Các thiết lập được thực hiện bằng Command Prompt thông thường sẽ đi tới `%LOCALAPPDATA%\VirtualStore\Program Files\Git\etc\gitconfig`
- Các thiết lập được thực hiện bằng Command Prompt với quyền Administrator sẽ đi tới `C:\Program Files\Git\etc\gitconfig`
- Hai vị trí này không đồng bộ với nhau, gây ra hành vi không mong đợi

**Giải pháp**: Khi thiết lập các tùy chọn cấp độ hệ thống (`--system`), hãy luôn chạy Command Prompt với quyền Administrator để đảm bảo các thiết lập áp dụng trên toàn hệ thống.

Để biết thêm thông tin: [VirtualStore - Inside Windows Vista User Account Control](https://learn.microsoft.com/en-us/previous-versions/technet-magazine/cc138019(v=msdn.10))

## Cấu hình Alias

Tạo phím tắt cho các lệnh thường dùng:

```
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.ci commit
git config --global alias.st status
git config --global alias.lg "log --oneline --graph --all"
```

Sau đó bạn có thể dùng `git co` thay vì `git checkout`, v.v.

## Đầu ra có màu sắc (Color Output)

Bật đầu ra có màu sắc để dễ đọc hơn:

```
git config --global color.ui auto
```

## Tên Branch mặc định

Thiết lập tên branch mặc định cho các repository mới:

```
git config --global init.defaultBranch main
```

## Công cụ Merge và Diff

Cấu hình các công cụ merge và diff ưa thích của bạn:

```
git config --global merge.tool vimdiff
git config --global diff.tool vimdiff
```

## Credential Helper

Lưu trữ thông tin xác thực để tránh phải nhập mật khẩu lặp đi lặp lại:

```
# Windows
git config --global credential.helper wincred

# Cache credentials for 1 hour
git config --global credential.helper 'cache --timeout=3600'
```

## Hành vi Push

Cấu hình hành vi push mặc định:

```
# Push only the current branch
git config --global push.default simple

# Push all matching branches
git config --global push.default matching
```

## Hủy thiết lập cấu hình

Để loại bỏ một cấu hình:

```
git config --global --unset user.name
git config --global --unset-all user.email
```

## Chỉnh sửa trực tiếp các tệp cấu hình

Bạn cũng có thể chỉnh sửa trực tiếp các tệp cấu hình:

```
git config --global --edit
git config --local --edit
```

## Tóm tắt hôm nay

Hiểu và cấu hình Git đúng cách là điều thiết yếu cho một quy trình làm việc suôn sẻ. Hệ thống cấu hình rất linh hoạt và mạnh mẽ, cho phép bạn tùy chỉnh Git để phù hợp với sở thích và môi trường làm việc của mình.

Hãy để tôi sắp xếp lại các lệnh và tham số Git đã học hôm nay:

* git config --list
* git config --global user.name
* git config --global user.email
* git config --global core.editor
* git config --global core.autocrlf
* git config --global alias.*
* git config --global --edit
* git config --global --unset
