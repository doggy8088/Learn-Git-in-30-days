# Ngày 10: Hiểu tên tuyệt đối của Git Object

Trong quá trình quản lý phiên bản Git, mỗi phiên bản đại diện cho một commit object. Vì các branch thường được tạo ra trong quá trình quản lý phiên bản, đồ thị commit kết quả có thể khá phức tạp. Vì vậy, cách xác định các phiên bản khác nhau hoặc nhanh chóng định vị các phiên bản cụ thể để lấy thông tin trở nên rất quan trọng. Bài viết này sẽ giúp bạn hiểu các khái niệm và phương pháp sử dụng tên object thường dùng trong Git.

## Tên tuyệt đối của Object

Trong Git, mỗi object có một id được tính bằng phép băm SHA1, và id này là cái gọi là "tên tuyệt đối". Nếu object là một commit object, thì đây là tên tuyệt đối của commit object. Vì vậy miễn là chúng ta tìm được tên tuyệt đối của commit object, chúng ta có thể lấy phiên bản đó bất cứ lúc nào. Như được chỉ ra bởi mũi tên trong hình sau, đây là commit object id chúng ta lấy được thông qua `git log`. Chúng ta có thể lấy thông tin chi tiết về commit object đó bất cứ lúc nào.

![hình ảnh](figures/10/01.png)

Nếu chúng ta muốn xem nội dung của commit object trong hình trên, chúng ta có thể sử dụng `git cat-file -p commitid` để lấy nó, như thể hiện trong hình sau:

![hình ảnh](figures/10/02.png)

## Cú pháp ngắn cho tên tuyệt đối của Object

Vì Git object id là kết quả của phép băm SHA1 trên nội dung, nó khá dài (40 ký tự). Khi chỉ định "tên tuyệt đối" trong Git, bạn có thể chỉ sử dụng vài ký tự đầu tiên thay thế, với tối thiểu 4 ký tự. Điều này có nghĩa là "tên tuyệt đối" có độ dài từ 4 đến 40 ký tự đều có thể được sử dụng để xác định một object.

Ví dụ, chúng ta cũng có thể thấy từ hình trên rằng nội dung của commit object này chứa một tree object, cũng có một tên tuyệt đối là `07c1321be49815d53eb2413f0ad5286010ebb6cc`. Vì vậy tôi cũng có thể sử dụng lại `git cat-file -p treeid` để lấy nội dung của tree object đó, như thể hiện trong hình sau:

![hình ảnh](figures/10/03.png)

Đôi khi chúng ta muốn lấy các bản ghi phiên bản và sẽ sử dụng lệnh `git log`, lệnh này cũng sẽ xuất ra kết quả so sánh các thay đổi cho mỗi tệp. Kết quả sẽ rất dài. Lúc này, bạn có thể sử dụng lệnh `git log --pretty=oneline` để lấy các bản ghi lịch sử ngắn gọn hơn, và bạn cũng có thể lấy "tên tuyệt đối" hoàn chỉnh của commit object, như thể hiện trong hình sau:

![hình ảnh](figures/10/04.png)

Một kỹ thuật thường dùng khác là chỉ xuất ra một phần của "tên tuyệt đối". Bạn có thể thực thi nó thông qua lệnh `git log --pretty=oneline --abbrev-commit`, như thể hiện trong hình sau:

![hình ảnh](figures/10/05.png)

## Tóm tắt hôm nay

Trên đây là cách sử dụng tên tuyệt đối. Do các đặc điểm của Git object, bạn có thể truy cập bất kỳ object nào trong Git Repository thông qua tên tuyệt đối của object. Còn nhiều lệnh git nữa sẽ sử dụng tên tuyệt đối. Quen thuộc với các khái niệm và cách biểu đạt này, bạn sẽ làm chủ Git object tốt hơn.

Hãy để tôi sắp xếp lại các lệnh và tham số Git đã học hôm nay:

* git log
* git cat-file -p [object_id]
* git log --pretty=oneline
* git log --pretty=oneline --abbrev-commit
