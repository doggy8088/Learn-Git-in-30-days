# Day 14: Git for Windows の設定オプション

Git for Windows のコマンドラインツールを使う方が、GUI ツールを操作するよりも確実に効率的です。その理由は、コマンドを通じて多くの繰り返しのバージョン管理タスクを自動化したり、複雑な標準作業手順（SOP）をシンプルなコマンド操作に変換したりできるからです。本記事では、Git for Windows コマンドラインツールの使用に関するいくつかの Tips を共有します。

## Git コマンドラインツールの設定オプションについて

Git コマンドラインツールには、設定できる「オプション」が数多くあります。これは、私たちが GUI ツールを使う際に通常 [ツール] -> [設定] でコマンド実行時の動作を微調整するのと同じです。最も一般的なのは、もちろん、Git for Windows を初めて使う際、`user.name` と `user.email` オプションを設定しなければならないことです。この 2 つのオプションが設定されていないと、`git commit` を実行する資格すらありません。

Git for Windows ツールで現在設定されているすべてのオプションを一覧表示するには、`git config --list` コマンドを使います。

**注意**：インターネット上のほとんどの Git 記事は Linux や Mac 環境のセットアップ方法を紹介しているため、私の記事は Windows プラットフォームの設定に焦点を当てます。ただし、保存パスの違いを除けば、コマンドの使い方は実際には同じです。

どのような「オプション」があるか確認したい場合は、コマンドプロンプトで `git help config` を実行して完全なドキュメントを表示するか、[git-config(1) Manual Page](https://www.kernel.org/pub/software/scm/git/docs/git-config.html) を参照してください。

## Git の設定レベルを理解する

Git には 3 つのレベルの設定があります。

1. **システムレベル**（`--system`）：システム上のすべてのユーザーに適用されます
   * 場所：`C:\Program Files\Git\etc\gitconfig`
   * **Windows で重要**：UAC が有効な場合、設定が `%LOCALAPPDATA%\VirtualStore\Program Files\Git\etc\gitconfig` にリダイレクトされることがあります
   * **推奨**：システムレベルのオプションを設定する際は、常にコマンドプロンプトを管理者として実行してください

2. **グローバルレベル**（`--global`）：現在のユーザーに適用されます
   * 場所：`C:\Users\[username]\.gitconfig` または `%USERPROFILE%\.gitconfig`
   * `user.name`、`user.email`、個人的な設定によく使われます

3. **ローカルレベル**（`--local`）：現在のリポジトリにのみ適用されます
   * 場所：リポジトリ内の `.git\config`
   * リポジトリを初期化またはクローンした際に自動的に作成されます

下位レベルの設定は上位レベルの設定を上書きします（ローカル > グローバル > システム）。

## 設定を表示する

現在のすべての設定を表示するには、以下を使います。

```
git config --list
```

特定のレベルの設定を表示するには、以下を使います。

```
git config --global --list
git config --local --list
git config --system --list
```

## ユーザー ID を設定する

最も基本的な設定は、ユーザー名とメールアドレスの設定です。

```
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

これらの設定は、あなたが行うすべてのコミットで使われます。

## デフォルトエディタを設定する

コミットメッセージ用に好みのテキストエディタを設定します。

```
git config --global core.editor "code --wait"  # VS Code
git config --global core.editor "notepad"      # Notepad
git config --global core.editor "vim"          # Vim
```

## 改行コードの設定

これはクロスプラットフォーム開発において重要です。

```
# Windows (convert LF to CRLF on checkout, CRLF to LF on commit)
git config --global core.autocrlf true

# Linux/Mac (convert CRLF to LF on commit, no conversion on checkout)
git config --global core.autocrlf input

# No conversion
git config --global core.autocrlf false
```

### 重要：Windows の UAC と VirtualStore

ユーザーアカウント制御（UAC）が有効な Windows Vista 以降では、システムレベルの設定を行う際に重要な考慮事項があります。

**問題**：Windows の VirtualStore 技術は、管理者でないプロセスがシステムディレクトリに書き込もうとすると、ファイル書き込みをリダイレクトします。つまり：
- 通常のコマンドプロンプトで行った設定は `%LOCALAPPDATA%\VirtualStore\Program Files\Git\etc\gitconfig` に保存されます
- 管理者コマンドプロンプトで行った設定は `C:\Program Files\Git\etc\gitconfig` に保存されます
- この 2 つの場所は同期しないため、予期しない動作の原因になります

**解決策**：システムレベルのオプション（`--system`）を設定する際は、設定がシステム全体に適用されるよう、常にコマンドプロンプトを管理者として実行してください。

詳細については、[VirtualStore - Inside Windows Vista User Account Control](https://learn.microsoft.com/en-us/previous-versions/technet-magazine/cc138019(v=msdn.10)) を参照してください。

## エイリアスを設定する

よく使うコマンドのショートカットを作成します。

```
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.ci commit
git config --global alias.st status
git config --global alias.lg "log --oneline --graph --all"
```

これにより、`git checkout` の代わりに `git co` を使うなどといったことができます。

## カラー出力

読みやすさを向上させるため、カラー出力を有効にします。

```
git config --global color.ui auto
```

## デフォルトブランチ名

新しいリポジトリのデフォルトブランチ名を設定します。

```
git config --global init.defaultBranch main
```

## マージおよび差分ツール

好みのマージおよび差分ツールを設定します。

```
git config --global merge.tool vimdiff
git config --global diff.tool vimdiff
```

## 資格情報ヘルパー

パスワードの繰り返し入力を避けるため、資格情報を保存します。

```
# Windows
git config --global credential.helper wincred

# Cache credentials for 1 hour
git config --global credential.helper 'cache --timeout=3600'
```

## プッシュの動作

デフォルトのプッシュ動作を設定します。

```
# Push only the current branch
git config --global push.default simple

# Push all matching branches
git config --global push.default matching
```

## 設定を解除する

設定を削除するには、以下を使います。

```
git config --global --unset user.name
git config --global --unset-all user.email
```

## 設定ファイルを直接編集する

設定ファイルを直接編集することもできます。

```
git config --global --edit
git config --local --edit
```

## 本日のまとめ

Git を理解し、適切に設定することは、スムーズなワークフローに不可欠です。設定システムは柔軟で強力であり、好みや作業環境に合わせて Git をカスタマイズできます。

本日学んだ Git コマンドとパラメータを整理しておきます。

* git config --list
* git config --global user.name
* git config --global user.email
* git config --global core.editor
* git config --global core.autocrlf
* git config --global alias.*
* git config --global --edit
* git config --global --unset
