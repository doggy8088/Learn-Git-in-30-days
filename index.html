三十天的旅程 The journey

Day 01–07

基礎觀念

先懂 Git 為什麼存在，再拆開它的物件與索引結構——知其所以然，指令自然記得住。

Day 08–16

分支與日常操作

分支、比對、暫存、標籤與 reflog，把每天都會用到的操作練到熟。

Day 17–23

合併與歷史修正

merge、reset、revert、cherry-pick、rebase——救回誤刪的分支，改寫歷史也不慌。

Day 24–28

遠端協作

GitHub 遠端儲存庫、多人協作流程、fork 與 pull request 的完整版控工作流。

Day 29–30

匯入與實務技巧

把 Subversion 專案搬進 Git，再分享工作中真正好用的操作技巧作結。

關於作者 About the author

黃保翕（Will 保哥），微軟 MVP、多奇數位創意技術總監。本書是他在 2013 年第 6 屆 iT 邦幫忙鐵人賽的參賽作品，三十天連載不間斷，最終拿下開發技術組年度鐵人與年度大獎。文章源自他帶領公司團隊從 Subversion 轉向 Git 的第一手經驗——踩過的坑、解過的問題，都寫進了這三十天裡。
