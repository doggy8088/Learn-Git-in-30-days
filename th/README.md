# เชี่ยวชาญ Git ใน 30 วัน

Author: Will Huang (Will 保哥)

![Git](figures/README/01.png)

## บทนำ

ในแวดวงการพัฒนาซอฟต์แวร์ การควบคุมเวอร์ชันของซอร์สโค้ดเป็นเรื่องที่สำคัญมาก ต่างจากระบบควบคุมเวอร์ชันแบบรวมศูนย์ (Centralized) อย่าง Subversion หรือ TFVC (Team Foundation Version Control) ตรงที่ Git เป็นระบบควบคุมเวอร์ชันแบบกระจายศูนย์ (DVCS; Distributed Version Control System) ซึ่งนำข้อดีมากมายมาสู่การควบคุมเวอร์ชัน และแก้ไขข้อด้อยของการควบคุมเวอร์ชันแบบรวมศูนย์ดั้งเดิม เช่น รองรับการทำงานแบบโลคัล สำรองข้อมูลได้ง่าย การแยก Branch และการ Merge ที่ทรงพลังและยืดหยุ่น และอื่น ๆ อีกมากมาย อย่างไรก็ตาม เนื่องจากการควบคุมเวอร์ชันด้วย Git แตกต่างจากเครื่องมือควบคุมเวอร์ชันแบบรวมศูนย์ดั้งเดิมอย่างมาก ทั้งในแง่แนวคิดการควบคุมเวอร์ชันและวิธีการใช้เครื่องมือ จึงทำให้มีช่วงการเรียนรู้ที่ค่อนข้างชัน (Learning Curve) ในอีก 30 วันข้างหน้า ผมหวังว่าจะช่วยให้คุณเข้าใจแก่นแท้ของการควบคุมเวอร์ชันด้วย Git อย่างครบถ้วน พร้อมแบ่งปันประสบการณ์การเรียนรู้ของผม รวมถึงปัญหาและวิธีแก้ไขที่เราพบเจอในระหว่างที่บริษัทของเราเปลี่ยนจาก Subversion มาใช้ Git

> **หมายเหตุเกี่ยวกับฉบับแปล:** ฉบับภาษาไทยนี้แปลจากฉบับภาษาอังกฤษของหนังสือที่ได้รับรางวัลเล่มนี้ โดยคงแนวคิดหลักและความถูกต้องทางเทคนิคของต้นฉบับไว้ พร้อมปรับเนื้อหาบางส่วนให้เหมาะกับแนวปฏิบัติของ Git ในปัจจุบันและผู้อ่านทั่วไป บางบทได้รับการเสริมตัวอย่างเพิ่มเติมและแนวปฏิบัติที่ดีที่สุดในปัจจุบัน
