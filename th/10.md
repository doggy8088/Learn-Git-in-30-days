# วันที่ 10: ทำความเข้าใจชื่อสัมบูรณ์ของ Git Object

ในกระบวนการควบคุมเวอร์ชันด้วย Git แต่ละเวอร์ชันแทน Commit Object หนึ่งตัว เนื่องจาก Branch มักถูกสร้างขึ้นในระหว่างการควบคุมเวอร์ชัน กราฟ Commit ที่ได้จึงอาจค่อนข้างซับซ้อน ดังนั้น วิธีระบุเวอร์ชันต่าง ๆ หรือค้นหาเวอร์ชันที่ระบุอย่างรวดเร็วเพื่อรับข้อมูลจึงกลายเป็นเรื่องสำคัญมาก บทความนี้จะช่วยให้คุณเข้าใจแนวคิดชื่อ Object และวิธีการใช้งานที่ใช้กันทั่วไปใน Git

## ชื่อสัมบูรณ์ของ Object

ใน Git Object แต่ละตัวมี ID ที่คำนวณจากการแฮช SHA1 และ ID นี้คือสิ่งที่เรียกว่า "ชื่อสัมบูรณ์ (Absolute Name)" หาก Object นั้นเป็น Commit Object นี่ก็คือชื่อสัมบูรณ์ของ Commit Object นั้น ดังนั้นตราบใดที่เราค้นหาชื่อสัมบูรณ์ของ Commit Object ได้ เราก็สามารถรับเวอร์ชันนั้นได้ทุกเมื่อ ดังที่ลูกศรชี้ในรูปต่อไปนี้ นี่คือ Commit Object ID ที่เราได้รับผ่าน `git log` เราสามารถรับข้อมูลโดยละเอียดเกี่ยวกับ Commit Object นั้นได้ทุกเมื่อ

![รูปภาพ](figures/10/01.png)

หากเราต้องการดูเนื้อหาของ Commit Object ในรูปข้างต้น เราสามารถใช้ `git cat-file -p commitid` เพื่อรับมันได้ ดังแสดงในรูปต่อไปนี้:

![รูปภาพ](figures/10/02.png)

## รูปแบบย่อของชื่อสัมบูรณ์ของ Object

เนื่องจาก Git Object ID เป็นผลลัพธ์ของการแฮช SHA1 กับเนื้อหา มันจึงค่อนข้างยาว (40 อักขระ) เมื่อระบุ "ชื่อสัมบูรณ์" ใน Git คุณสามารถใช้อักขระเพียงสองสามตัวแรกแทนได้ โดยขั้นต่ำคือ 4 อักขระ ซึ่งหมายความว่า "ชื่อสัมบูรณ์" ที่มีความยาวระหว่าง 4 ถึง 40 อักขระ ล้วนสามารถใช้ระบุ Object ได้ทั้งหมด

ตัวอย่างเช่น เรายังสามารถเห็นได้จากรูปข้างต้นว่า เนื้อหาของ Commit Object นี้มี Tree Object อยู่ด้วย ซึ่งก็มีชื่อสัมบูรณ์เป็น `07c1321be49815d53eb2413f0ad5286010ebb6cc` เช่นกัน ดังนั้นผมจึงสามารถใช้ `git cat-file -p treeid` อีกครั้งเพื่อรับเนื้อหาของ Tree Object นั้นได้ ดังแสดงในรูปต่อไปนี้:

![รูปภาพ](figures/10/03.png)

บางครั้งเราต้องการรับบันทึกเวอร์ชันและจะใช้คำสั่ง `git log` ซึ่งจะแสดงผลการเปรียบเทียบการเปลี่ยนแปลงสำหรับแต่ละไฟล์ด้วย ผลลัพธ์จะยาวมาก ในเวลานี้ คุณสามารถใช้คำสั่ง `git log --pretty=oneline` เพื่อรับบันทึกประวัติที่กระชับยิ่งขึ้น และยังสามารถรับ "ชื่อสัมบูรณ์" ที่สมบูรณ์ของ Commit Object ได้ด้วย ดังแสดงในรูปต่อไปนี้:

![รูปภาพ](figures/10/04.png)

เทคนิคอีกอย่างที่ใช้กันบ่อยคือการแสดงเพียงบางส่วนของ "ชื่อสัมบูรณ์" คุณสามารถดำเนินการผ่านคำสั่ง `git log --pretty=oneline --abbrev-commit` ได้ ดังแสดงในรูปต่อไปนี้:

![รูปภาพ](figures/10/05.png)

## สรุปของวันนี้

ข้างต้นคือการใช้งานชื่อสัมบูรณ์ เนื่องจากลักษณะของ Git Object คุณสามารถเข้าถึง Object ใด ๆ ใน Git Repository ผ่านชื่อสัมบูรณ์ของ Object ได้ ยังมีคำสั่ง git อีกมากมายที่จะใช้ชื่อสัมบูรณ์ เมื่อคุ้นเคยกับแนวคิดและรูปแบบเหล่านี้ คุณจะเชี่ยวชาญ Git Object ได้ดียิ่งขึ้น

ขอผมเรียบเรียงคำสั่งและพารามิเตอร์ Git ที่เรียนรู้ในวันนี้อีกครั้ง:

* git log
* git cat-file -p [object_id]
* git log --pretty=oneline
* git log --pretty=oneline --abbrev-commit
