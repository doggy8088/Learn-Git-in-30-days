# วันที่ 14: ตัวเลือกการกำหนดค่า Git for Windows

การใช้เครื่องมือ Command Line ของ Git for Windows นั้นมีประสิทธิภาพมากกว่าการดำเนินการผ่านเครื่องมือ GUI อย่างแน่นอน เหตุผลก็คือ คุณสามารถทำให้งานควบคุมเวอร์ชันที่ซ้ำซากจำนวนมากเป็นอัตโนมัติได้ผ่านคำสั่ง หรือเปลี่ยนขั้นตอนการปฏิบัติงานมาตรฐาน (SOP) ที่ซับซ้อนให้กลายเป็นการดำเนินการด้วยคำสั่งอย่างง่าย บทความนี้จะแบ่งปันเคล็ดลับบางอย่างในการใช้เครื่องมือ Command Line ของ Git for Windows

## เกี่ยวกับตัวเลือกการกำหนดค่าของเครื่องมือ Command Line ของ Git

ในเครื่องมือ Command Line ของ Git มี "ตัวเลือก" มากมายที่สามารถตั้งค่าได้ เช่นเดียวกับที่เรามักจะมี [Tools] -> [Preferences] เมื่อใช้เครื่องมือ GUI เพื่อปรับแต่งพฤติกรรมบางอย่างเมื่อคำสั่งถูกดำเนินการ ตัวอย่างที่พบบ่อยที่สุด แน่นอนว่า คือเมื่อคุณใช้ Git for Windows ครั้งแรก คุณต้องตั้งค่าตัวเลือก `user.name` และ `user.email` หากไม่ได้ตั้งค่าตัวเลือกสองตัวนี้ คุณจะไม่มีสิทธิ์ดำเนินการ `git commit` เลยด้วยซ้ำ

ในการแสดงรายการตัวเลือกทั้งหมดที่ตั้งค่าไว้ในเครื่องมือ Git for Windows ปัจจุบัน คุณสามารถใช้คำสั่ง `git config --list` ได้

**หมายเหตุ**: เนื่องจากบทความ Git ส่วนใหญ่บนอินเทอร์เน็ตแนะนำวิธีตั้งค่าสภาพแวดล้อม Linux หรือ Mac บทความของผมจะเน้นไปที่การกำหนดค่าบนแพลตฟอร์ม Windows อย่างไรก็ตาม ยกเว้นเส้นทางจัดเก็บที่แตกต่างกัน การใช้งานคำสั่งนั้นแท้จริงแล้วเหมือนกัน

หากคุณต้องการตรวจสอบว่ามี "ตัวเลือก" อะไรบ้าง คุณสามารถดำเนินการ `git help config` ที่พร้อมท์คำสั่งเพื่อแสดงเอกสารฉบับสมบูรณ์ หรือเยี่ยมชม [git-config(1) Manual Page](https://www.kernel.org/pub/software/scm/git/docs/git-config.html)

## ทำความเข้าใจระดับการกำหนดค่าของ Git

Git มีระดับการกำหนดค่าสามระดับ:

1. **ระดับระบบ (System)** (`--system`): ใช้กับผู้ใช้ทั้งหมดในระบบ
   * ตำแหน่ง: `C:\Program Files\Git\etc\gitconfig`
   * **ข้อสำคัญสำหรับ Windows**: เมื่อเปิดใช้งาน UAC การตั้งค่าอาจถูกเปลี่ยนเส้นทางไปยัง `%LOCALAPPDATA%\VirtualStore\Program Files\Git\etc\gitconfig`
   * **คำแนะนำ**: ให้เรียกใช้ Command Prompt ในฐานะผู้ดูแลระบบ (Administrator) เสมอเมื่อตั้งค่าตัวเลือกระดับระบบ
   
2. **ระดับส่วนกลาง (Global)** (`--global`): ใช้กับผู้ใช้ปัจจุบัน
   * ตำแหน่ง: `C:\Users\[username]\.gitconfig` หรือ `%USERPROFILE%\.gitconfig`
   * ใช้กันทั่วไปสำหรับ `user.name`, `user.email` และการกำหนดลักษณะส่วนบุคคล
   
3. **ระดับโลคัล (Local)** (`--local`): ใช้กับ Repository ปัจจุบันเท่านั้น
   * ตำแหน่ง: `.git\config` ใน Repository
   * ถูกสร้างขึ้นโดยอัตโนมัติเมื่อคุณเริ่มต้นหรือ Clone Repository

การกำหนดค่าในระดับที่ต่ำกว่าจะแทนที่ระดับที่สูงกว่า (local > global > system)

## การดูการกำหนดค่า

ในการดูการกำหนดค่าปัจจุบันทั้งหมด:

```
git config --list
```

ในการดูการกำหนดค่าจากระดับที่ระบุ:

```
git config --global --list
git config --local --list
git config --system --list
```

## การตั้งค่าตัวตนของผู้ใช้

การกำหนดค่าพื้นฐานที่สุดคือการตั้งชื่อผู้ใช้และอีเมลของคุณ:

```
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

การตั้งค่าเหล่านี้จะถูกใช้ในทุก Commit ที่คุณทำ

## การกำหนดค่าโปรแกรมแก้ไขเริ่มต้น

ตั้งค่าโปรแกรมแก้ไขข้อความที่คุณต้องการสำหรับข้อความ Commit:

```
git config --global core.editor "code --wait"  # VS Code
git config --global core.editor "notepad"      # Notepad
git config --global core.editor "vim"          # Vim
```

## การกำหนดค่าการสิ้นสุดบรรทัด (Line Ending)

สิ่งนี้สำคัญสำหรับการพัฒนาข้ามแพลตฟอร์ม:

```
# Windows (convert LF to CRLF on checkout, CRLF to LF on commit)
git config --global core.autocrlf true

# Linux/Mac (convert CRLF to LF on commit, no conversion on checkout)
git config --global core.autocrlf input

# No conversion
git config --global core.autocrlf false
```

### ข้อสำคัญ: Windows UAC และ VirtualStore

บน Windows Vista และเวอร์ชันที่ใหม่กว่า เมื่อเปิดใช้งาน User Account Control (UAC) มีข้อควรพิจารณาที่สำคัญเมื่อตั้งค่าการกำหนดค่าระดับระบบ:

**ปัญหา**: เทคโนโลยี VirtualStore ของ Windows จะเปลี่ยนเส้นทางการเขียนไฟล์เมื่อกระบวนการที่ไม่ใช่ผู้ดูแลระบบพยายามเขียนไปยังไดเรกทอรีของระบบ ซึ่งหมายความว่า:
- การตั้งค่าที่ทำด้วย Command Prompt ธรรมดาจะไปยัง `%LOCALAPPDATA%\VirtualStore\Program Files\Git\etc\gitconfig`
- การตั้งค่าที่ทำด้วย Command Prompt ของผู้ดูแลระบบจะไปยัง `C:\Program Files\Git\etc\gitconfig`
- สองตำแหน่งนี้ไม่ซิงค์กัน ทำให้เกิดพฤติกรรมที่ไม่คาดคิด

**วิธีแก้ปัญหา**: เมื่อตั้งค่าตัวเลือกระดับระบบ (`--system`) ให้เรียกใช้ Command Prompt ในฐานะผู้ดูแลระบบเสมอ เพื่อให้แน่ใจว่าการตั้งค่าจะใช้กับทั้งระบบ

สำหรับข้อมูลเพิ่มเติม: [VirtualStore - Inside Windows Vista User Account Control](https://learn.microsoft.com/en-us/previous-versions/technet-magazine/cc138019(v=msdn.10))

## การกำหนดค่านามแฝง (Alias)

สร้างทางลัดสำหรับคำสั่งที่ใช้บ่อย:

```
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.ci commit
git config --global alias.st status
git config --global alias.lg "log --oneline --graph --all"
```

จากนั้นคุณสามารถใช้ `git co` แทน `git checkout` เป็นต้น

## ผลลัพธ์แบบมีสี

เปิดใช้งานผลลัพธ์แบบมีสีเพื่อให้อ่านได้ง่ายขึ้น:

```
git config --global color.ui auto
```

## ชื่อ Branch เริ่มต้น

ตั้งชื่อ Branch เริ่มต้นสำหรับ Repository ใหม่:

```
git config --global init.defaultBranch main
```

## เครื่องมือ Merge และ Diff

กำหนดค่าเครื่องมือ Merge และ Diff ที่คุณต้องการ:

```
git config --global merge.tool vimdiff
git config --global diff.tool vimdiff
```

## ตัวช่วยจัดการข้อมูลประจำตัว (Credential Helper)

จัดเก็บข้อมูลประจำตัวเพื่อหลีกเลี่ยงการป้อนรหัสผ่านซ้ำ ๆ:

```
# Windows
git config --global credential.helper wincred

# Cache credentials for 1 hour
git config --global credential.helper 'cache --timeout=3600'
```

## พฤติกรรมการ Push

กำหนดค่าพฤติกรรมการ Push เริ่มต้น:

```
# Push only the current branch
git config --global push.default simple

# Push all matching branches
git config --global push.default matching
```

## การยกเลิกการตั้งค่าการกำหนดค่า

ในการลบการกำหนดค่า:

```
git config --global --unset user.name
git config --global --unset-all user.email
```

## การแก้ไขไฟล์กำหนดค่าโดยตรง

คุณยังสามารถแก้ไขไฟล์กำหนดค่าได้โดยตรง:

```
git config --global --edit
git config --local --edit
```

## สรุปของวันนี้

การทำความเข้าใจและกำหนดค่า Git อย่างเหมาะสมเป็นสิ่งจำเป็นสำหรับขั้นตอนการทำงานที่ราบรื่น ระบบการกำหนดค่านั้นมีความยืดหยุ่นและทรงพลัง ช่วยให้คุณปรับแต่ง Git ให้ตรงกับความต้องการและสภาพแวดล้อมการทำงานของคุณได้

ขอผมเรียบเรียงคำสั่งและพารามิเตอร์ Git ที่เรียนรู้ในวันนี้อีกครั้ง:

* git config --list
* git config --global user.name
* git config --global user.email
* git config --global core.editor
* git config --global core.autocrlf
* git config --global alias.*
* git config --global --edit
* git config --global --unset
