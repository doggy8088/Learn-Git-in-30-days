# Hari 10: Memahami Nama Absolut Objek Git

Dalam proses kontrol versi Git, setiap versi mewakili sebuah objek commit. Karena branch sering dibuat selama kontrol versi, grafik commit yang dihasilkan bisa cukup kompleks. Oleh karena itu, cara mengidentifikasi versi yang berbeda atau dengan cepat menemukan versi tertentu untuk mendapatkan informasi menjadi sangat penting. Artikel ini akan membantu Anda memahami konsep nama objek yang umum digunakan dan metode penggunaannya di Git.

## Nama Absolut Objek

Di Git, setiap objek memiliki id yang dihitung dengan hashing SHA1, dan id ini adalah yang disebut "nama absolut." Jika objek adalah objek commit, maka ini adalah nama absolut dari objek commit. Jadi selama kita menemukan nama absolut dari objek commit, kita dapat memperoleh versi tersebut kapan saja. Seperti yang ditunjukkan oleh panah pada gambar berikut, ini adalah id objek commit yang kami peroleh melalui `git log`. Kita dapat memperoleh informasi terperinci tentang objek commit tersebut kapan saja.

![gambar](figures/10/01.png)

Jika kita ingin melihat isi objek commit pada gambar di atas, kita dapat menggunakan `git cat-file -p commitid` untuk mendapatkannya, seperti yang ditunjukkan pada gambar berikut:

![gambar](figures/10/02.png)

## Sintaks Singkat untuk Nama Absolut Objek

Karena id objek Git adalah hasil hashing SHA1 dari isi, ia cukup panjang (40 karakter). Ketika menentukan "nama absolut" di Git, Anda dapat menggunakan hanya beberapa karakter pertama sebagai gantinya, dengan minimal 4 karakter. Ini berarti bahwa "nama absolut" dengan panjang antara 4 hingga 40 karakter semuanya dapat digunakan untuk mengidentifikasi sebuah objek.

Misalnya, kita juga dapat melihat dari gambar di atas bahwa isi objek commit ini berisi objek tree, yang juga memiliki nama absolut `07c1321be49815d53eb2413f0ad5286010ebb6cc`. Jadi saya juga dapat menggunakan `git cat-file -p treeid` lagi untuk mendapatkan isi objek tree tersebut, seperti yang ditunjukkan pada gambar berikut:

![gambar](figures/10/03.png)

Terkadang kita ingin mendapatkan catatan versi dan akan menggunakan perintah `git log`, yang juga akan mengeluarkan hasil perbandingan perubahan untuk setiap file. Hasilnya akan sangat panjang. Pada saat ini, Anda dapat menggunakan perintah `git log --pretty=oneline` untuk mendapatkan catatan historis yang lebih ringkas, dan Anda juga dapat memperoleh "nama absolut" lengkap dari objek commit, seperti yang ditunjukkan pada gambar berikut:

![gambar](figures/10/04.png)

Teknik lain yang umum digunakan adalah hanya mengeluarkan sebagian dari "nama absolut." Anda dapat menjalankannya melalui perintah `git log --pretty=oneline --abbrev-commit`, seperti yang ditunjukkan pada gambar berikut:

![gambar](figures/10/05.png)

## Ringkasan Hari Ini

Di atas adalah penggunaan nama absolut. Karena karakteristik objek Git, Anda dapat mengakses objek apa pun dalam repositori Git melalui nama absolut objek. Ada lebih banyak lagi perintah git yang akan menggunakan nama absolut. Dengan terbiasa dengan konsep dan ekspresi ini, Anda akan lebih menguasai objek Git.

Izinkan saya menyusun kembali perintah dan parameter Git yang dipelajari hari ini:

* git log
* git cat-file -p [object_id]
* git log --pretty=oneline
* git log --pretty=oneline --abbrev-commit
