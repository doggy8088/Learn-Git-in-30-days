# Hari 19: Mengatur Daftar Abaikan .gitignore

Ketika mengembangkan sebuah proyek, file baru mungkin sering muncul di direktori kerja (seperti file sementara atau file cache yang dihasilkan oleh alat pengembangan seperti Visual Studio). Banyak dari file ini tidak perlu disertakan dalam kontrol versi dan harus dikecualikan. Kami menyebut ini "daftar abaikan".

## Memahami .gitignore

File `.gitignore` menentukan file yang sengaja tidak terlacak yang harus diabaikan oleh Git. Di Git, file `.gitignore` digunakan untuk mendefinisikan "daftar abaikan". Tujuan utamanya adalah mengecualikan file yang tidak perlu ditambahkan ke kontrol versi. File atau jalur (yang dapat menyertakan wildcard) yang tercantum dalam file ini tidak akan muncul dalam hasil `git status`, dan secara alami tidak akan ditambahkan ketika menjalankan `git add`.

Namun, ini hanya berlaku untuk `Untracked files`. File yang sudah terlacak oleh Git (`Staged files`) tidak terpengaruh oleh file `.gitignore`.

## Membuat .gitignore Melalui GitHub

Jika Anda pernah membuat proyek di GitHub, Anda mungkin pernah menggunakan fitur ini. Ketika membuat repositori baru, Anda dapat memilih daftar abaikan yang telah ditentukan sebelumnya yang dibantu GitHub untuk Anda siapkan. Daftar abaikan ini sebenarnya hanyalah file bernama `.gitignore`, yang ditempatkan di direktori akar proyek secara default.

Anda dapat memilih dari berbagai templat seperti:
- Node
- Python
- Java
- C#
- Visual Studio
- Dan banyak lagi

## Membuat .gitignore Secara Manual

Cukup buat file bernama `.gitignore` di akar repositori Anda:

```
# On Windows
echo node_modules/ > .gitignore

# On Linux/Mac
echo "node_modules/" > .gitignore
```

Atau buat secara manual dengan editor teks.

## Pola Dasar

### Mengabaikan File Tertentu

```
config.local.js
secrets.txt
```

### Mengabaikan File dengan Ekstensi Tertentu

```
*.log
*.tmp
*.cache
```

### Mengabaikan Direktori

```
node_modules/
dist/
build/
```

Perhatikan garis miring di akhir untuk menunjukkan direktori.

### Mengabaikan File di Direktori Mana Pun

```
# Ignore all .log files in any directory
**/*.log
```

## Pola Lanjutan

### Negasi (Pengecualian)

Gunakan `!` untuk membuat pengecualian:

```
# Ignore all .log files
*.log

# But don't ignore important.log
!important.log
```

### Mengabaikan File Hanya di Direktori Tertentu

```
# Ignore test.txt only in root directory
/test.txt

# Ignore test.txt in any subdirectory, but not root
*/test.txt
```

### Beberapa Ekstensi

```
# Ignore multiple file types
*.{jpg,png,gif}
```

## .gitignore Global

Untuk pola yang ingin Anda abaikan di semua repositori:

```
git config --global core.excludesfile ~/.gitignore_global
```

Kemudian buat `~/.gitignore_global` dengan pola Anda.

## Mengabaikan File yang Sudah Terlacak

Jika Anda secara tidak sengaja melakukan commit file yang seharusnya diabaikan:

```
# Remove from Git but keep the file
git rm --cached filename

# Remove directory from Git but keep it
git rm -r --cached directory/
```

Kemudian tambahkan pola ke `.gitignore` dan lakukan commit.

## Melihat File yang Diabaikan

Untuk melihat file mana yang diabaikan:

```
git status --ignored
```

## Memeriksa Mengapa File Diabaikan

Untuk melihat pola mana yang menyebabkan file diabaikan:

```
git check-ignore -v filename
```

## File Templat .gitignore

GitHub menyediakan file templat .gitignore untuk berbagai bahasa dan framework:

* https://github.com/github/gitignore

## Komentar di .gitignore

Gunakan `#` untuk komentar:

```
# This is a comment
*.log  # Inline comment
```

## Praktik Terbaik

1. **Commit .gitignore lebih awal**: Tambahkan di awal proyek Anda
2. **Bersikap spesifik**: Hindari pola yang terlalu luas
3. **Dokumentasikan alasannya**: Gunakan komentar untuk menjelaskan pola yang tidak jelas
4. **Jaga agar tetap teratur**: Kelompokkan pola terkait bersama-sama
5. **Gunakan templat**: Mulai dengan templat khusus bahasa
6. **Variasi lokal**: Gunakan `.git/info/exclude` untuk pola pribadi

## .gitignore Subdirektori

Anda dapat memiliki file `.gitignore` di subdirektori. Pola bersifat relatif terhadap lokasi file `.gitignore`.
