# Hari 14: Opsi Konfigurasi Git for Windows

Menggunakan alat baris perintah Git for Windows jelas lebih efisien daripada beroperasi melalui alat GUI. Alasannya adalah Anda dapat mengotomatiskan banyak tugas kontrol versi yang berulang melalui perintah, atau mengubah prosedur operasi standar (SOP) yang kompleks menjadi operasi perintah yang sederhana. Artikel ini akan berbagi beberapa tips untuk menggunakan alat baris perintah Git for Windows.

## Tentang Opsi Konfigurasi Alat Baris Perintah Git

Dalam alat baris perintah Git, ada banyak "opsi" yang dapat diatur, sama seperti kita biasanya memiliki [Tools] -> [Preferences] ketika menggunakan alat GUI, untuk menyetel beberapa perilaku ketika perintah dijalankan. Yang paling umum, tentu saja, adalah ketika Anda pertama kali menggunakan Git for Windows, Anda harus mengatur opsi `user.name` dan `user.email`. Tanpa kedua opsi ini diatur, Anda bahkan tidak memiliki hak untuk menjalankan `git commit`.

Untuk mencantumkan semua opsi yang saat ini diatur dalam alat Git for Windows, Anda dapat menggunakan perintah `git config --list`.

**Catatan**: Karena sebagian besar artikel Git di internet memperkenalkan cara mengatur lingkungan Linux atau Mac, artikel saya akan berfokus pada konfigurasi platform Windows. Namun, kecuali jalur penyimpanannya berbeda, penggunaan perintahnya sebenarnya sama.

Jika Anda ingin memeriksa "opsi" apa saja yang tersedia, Anda dapat menjalankan `git help config` pada prompt perintah untuk menampilkan dokumentasi lengkap atau mengunjungi [Halaman Manual git-config(1)](https://www.kernel.org/pub/software/scm/git/docs/git-config.html).

## Memahami Tingkat Konfigurasi Git

Git memiliki tiga tingkat konfigurasi:

1. **Tingkat sistem** (`--system`): Berlaku untuk semua pengguna di sistem
   * Lokasi: `C:\Program Files\Git\etc\gitconfig`
   * **Penting untuk Windows**: Dengan UAC diaktifkan, pengaturan dapat dialihkan ke `%LOCALAPPDATA%\VirtualStore\Program Files\Git\etc\gitconfig`
   * **Rekomendasi**: Selalu jalankan Command Prompt sebagai Administrator ketika mengatur opsi tingkat sistem

2. **Tingkat global** (`--global`): Berlaku untuk pengguna saat ini
   * Lokasi: `C:\Users\[username]\.gitconfig` atau `%USERPROFILE%\.gitconfig`
   * Umumnya digunakan untuk `user.name`, `user.email`, dan preferensi pribadi

3. **Tingkat lokal** (`--local`): Hanya berlaku untuk repositori saat ini
   * Lokasi: `.git\config` di repositori
   * Dibuat secara otomatis ketika Anda menginisialisasi atau mengkloning repositori

Konfigurasi pada tingkat yang lebih rendah menimpa tingkat yang lebih tinggi (lokal > global > sistem).

## Melihat Konfigurasi

Untuk melihat semua konfigurasi saat ini:

```
git config --list
```

Untuk melihat konfigurasi dari tingkat tertentu:

```
git config --global --list
git config --local --list
git config --system --list
```

## Mengatur Identitas Pengguna

Konfigurasi paling dasar adalah mengatur nama pengguna dan email Anda:

```
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

Pengaturan ini digunakan dalam setiap commit yang Anda buat.

## Mengonfigurasi Editor Default

Atur editor teks pilihan Anda untuk pesan commit:

```
git config --global core.editor "code --wait"  # VS Code
git config --global core.editor "notepad"      # Notepad
git config --global core.editor "vim"          # Vim
```

## Konfigurasi Akhir Baris

Ini penting untuk pengembangan lintas platform:

```
# Windows (convert LF to CRLF on checkout, CRLF to LF on commit)
git config --global core.autocrlf true

# Linux/Mac (convert CRLF to LF on commit, no conversion on checkout)
git config --global core.autocrlf input

# No conversion
git config --global core.autocrlf false
```

### Penting: UAC Windows dan VirtualStore

Pada Windows Vista dan yang lebih baru dengan User Account Control (UAC) diaktifkan, ada pertimbangan penting ketika mengatur konfigurasi tingkat sistem:

**Masalahnya**: Teknologi VirtualStore Windows mengalihkan penulisan file ketika proses non-administrator mencoba menulis ke direktori sistem. Ini berarti:
- Pengaturan yang dibuat dengan Command Prompt biasa masuk ke `%LOCALAPPDATA%\VirtualStore\Program Files\Git\etc\gitconfig`
- Pengaturan yang dibuat dengan Command Prompt Administrator masuk ke `C:\Program Files\Git\etc\gitconfig`
- Kedua lokasi ini tidak tersinkronisasi, menyebabkan perilaku yang tidak terduga

**Solusinya**: Ketika mengatur opsi tingkat sistem (`--system`), selalu jalankan Command Prompt sebagai Administrator untuk memastikan pengaturan berlaku di seluruh sistem.

Untuk informasi lebih lanjut: [VirtualStore - Inside Windows Vista User Account Control](https://learn.microsoft.com/en-us/previous-versions/technet-magazine/cc138019(v=msdn.10))

## Mengonfigurasi Alias

Buat pintasan untuk perintah yang umum digunakan:

```
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.ci commit
git config --global alias.st status
git config --global alias.lg "log --oneline --graph --all"
```

Kemudian Anda dapat menggunakan `git co` sebagai pengganti `git checkout`, dan sebagainya.

## Output Berwarna

Aktifkan output berwarna untuk keterbacaan yang lebih baik:

```
git config --global color.ui auto
```

## Nama Branch Default

Atur nama branch default untuk repositori baru:

```
git config --global init.defaultBranch main
```

## Alat Merge dan Diff

Konfigurasikan alat merge dan diff pilihan Anda:

```
git config --global merge.tool vimdiff
git config --global diff.tool vimdiff
```

## Credential Helper

Simpan kredensial untuk menghindari entri kata sandi berulang:

```
# Windows
git config --global credential.helper wincred

# Cache credentials for 1 hour
git config --global credential.helper 'cache --timeout=3600'
```

## Perilaku Push

Konfigurasikan perilaku push default:

```
# Push only the current branch
git config --global push.default simple

# Push all matching branches
git config --global push.default matching
```

## Menghapus Konfigurasi

Untuk menghapus sebuah konfigurasi:

```
git config --global --unset user.name
git config --global --unset-all user.email
```

## Mengedit File Konfigurasi Secara Langsung

Anda juga dapat mengedit file konfigurasi secara langsung:

```
git config --global --edit
git config --local --edit
```

Memahami dan mengonfigurasi Git dengan benar sangat penting untuk alur kerja yang lancar. Sistem konfigurasi ini fleksibel dan kuat, memungkinkan Anda menyesuaikan Git agar sesuai dengan preferensi dan lingkungan kerja Anda.
