# Hari 24: Menggunakan Repositori Jauh GitHub - Bermula

GitHub kini ialah platform pengurusan Git dalam talian yang paling meluas digunakan di dunia. Ia merangkumi pelaksanaan repositori jauh Git yang lengkap, mekanisme penjejakan isu dan laporan yang komprehensif, serta beribu-ribu projek sumber terbuka yang menggunakan GitHub untuk kawalan versi Git. Malah dalam banyak syarikat, GitHub diterima pakai sebagai platform Git utama. Artikel ini akan membimbing anda melalui penggunaan GitHub yang paling asas.

## Apakah GitHub?

GitHub ialah platform berasaskan web yang:
* Menghoskan repositori Git dalam awan
* Menyediakan alat kerjasama (isu, pull request, papan projek)
* Menawarkan CI/CD melalui GitHub Actions
* Membolehkan semakan kod dan perbincangan
* Menyediakan pengehosan percuma untuk projek sumber terbuka
* Berfungsi sebagai platform sosial untuk pembangun dan projek sumber terbuka

## Mencipta Akaun GitHub

1. Pergi ke https://github.com
2. Klik "Sign up"
3. Ikuti proses pendaftaran
4. Sahkan alamat e-mel anda

## Mencipta Repositori Baharu di GitHub

Terdapat dua pendekatan utama apabila mencipta repositori GitHub:

1. **Repositori kosong (tiada commit awal)**: Terbaik apabila anda mempunyai repositori setempat sedia ada untuk di-push
2. **Repositori yang dimulakan (dengan commit awal)**: GitHub mencipta fail README, .gitignore, dan/atau lesen untuk anda

### Mencipta Repositori Kosong

1. Klik ikon "+" di penjuru kanan atas
2. Pilih "New repository"
3. Isikan:
   * **Nama repositori (Repository name)**
   * **Penerangan (Description)** (pilihan)
   * **Awam atau Peribadi (Public or Private)**
   * **JANGAN tandakan** "Initialize this repository with a README"
   * Biarkan .gitignore dan lesen sebagai "None"
4. Klik "Create repository"

Selepas penciptaan, GitHub menunjukkan arahan untuk push repositori sedia ada.

### Mencipta Repositori yang Dimulakan

1. Ikuti langkah 1-3 di atas
2. **Tandakan** "Initialize this repository with a README"
3. Secara pilihan pilih:
   * **Templat .gitignore** untuk bahasa anda
   * **Lesen** untuk projek anda
4. Klik "Create repository"

GitHub akan mencipta commit awal dengan fail yang dipilih.

## Menyambungkan Repositori Setempat ke GitHub

### Pilihan 1: Push Repositori Sedia Ada

```
# Add remote
git remote add origin https://github.com/username/repo-name.git

# Push to GitHub
git push -u origin main
```

### Pilihan 2: Klon daripada GitHub

```
# Clone the repository
git clone https://github.com/username/repo-name.git

# Navigate to the directory
cd repo-name
```

## Memahami Remote

Remote ialah rujukan kepada repositori yang dihoskan di tempat lain. Perintah lazim:

```
# List remotes
git remote -v

# Add a remote
git remote add <name> <url>

# Remove a remote
git remote remove <name>

# Rename a remote
git remote rename <old> <new>

# Change remote URL
git remote set-url origin <new-url>
```

## Push ke GitHub

Push commit anda ke GitHub:

```
# Push to the default branch
git push origin main

# Push all branches
git push --all

# Push tags
git push --tags
```

Bendera `-u` menetapkan penjejakan upstream:

```
git push -u origin main
# After this, you can just use:
git push
```

## Pull daripada GitHub

Dapatkan kemas kini daripada GitHub:

```
# Fetch changes
git fetch origin

# Fetch and merge
git pull origin main

# If upstream is set
git pull
```

## Kaedah Pengesahan

### HTTPS

Memerlukan nama pengguna dan kata laluan/token:

```
https://github.com/username/repo-name.git
```

### SSH

Memerlukan persediaan kunci SSH:

```
git@github.com:username/repo-name.git
```

Menyediakan kunci SSH:

```
# Generate SSH key
ssh-keygen -t ed25519 -C "your.email@example.com"

# Add to ssh-agent
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

# Copy public key
cat ~/.ssh/id_ed25519.pub
# Add this key to GitHub settings
```

### Token Akses Peribadi (Personal Access Token)

Untuk pengesahan HTTPS:

1. Pergi ke GitHub Settings > Developer settings > Personal access tokens
2. Jana token baharu
3. Gunakan token sebagai kata laluan semasa push

## Ciri-ciri GitHub

### Isu (Issues)

Jejak pepijat, penambahbaikan, dan tugas:

* Cipta tajuk yang deskriptif
* Sediakan langkah penghasilan semula untuk pepijat
* Gunakan label untuk organisasi
* Rujuk commit dan pull request

### Wiki

Dokumentasi untuk projek anda:

* Panduan bermula
* Dokumentasi API
* Soalan Lazim (FAQ)
* Rajah seni bina

### Projek (Projects)

Susun kerja dengan papan Kanban:

* To Do
* In Progress
* Done

### Keluaran (Releases)

Tandakan pencapaian penting:

1. Pergi ke "Releases"
2. Klik "Draft a new release"
3. Pilih tag
4. Tambah nota keluaran
5. Lampirkan binari jika perlu

## Amalan Terbaik Aliran Kerja GitHub

1. **Commit dengan kerap**: Buat commit yang kecil dan logik
2. **Tulis mesej yang baik**: Terangkan mengapa, bukan sekadar apa
3. **Pull sebelum push**: Sentiasa dapatkan perubahan terkini terlebih dahulu
4. **Gunakan cabang**: Jangan commit terus ke main
5. **Semak kod**: Gunakan pull request untuk perubahan

## Tugas Lazim

### Fork Sesebuah Repositori

1. Klik "Fork" pada halaman repositori
2. Klon fork anda:
   ```
   git clone https://github.com/your-username/repo-name.git
   ```
3. Tambah remote upstream:
   ```
   git remote add upstream https://github.com/original-owner/repo-name.git
   ```

### Menyegerakkan Fork

```
git fetch upstream
git checkout main
git merge upstream/main
git push origin main
```
