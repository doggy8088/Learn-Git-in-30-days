# Hari 19: Menetapkan Senarai Abaikan .gitignore

Apabila membangunkan projek, fail baharu mungkin kerap muncul dalam direktori kerja (seperti fail sementara atau fail cache yang dijana oleh alat pembangunan seperti Visual Studio). Banyak fail ini tidak perlu dimasukkan dalam kawalan versi dan harus dikecualikan. Kami memanggil ini "senarai abaikan."

## Memahami .gitignore

Fail `.gitignore` menentukan fail yang tidak dijejak secara sengaja yang harus diabaikan oleh Git. Dalam Git, fail `.gitignore` digunakan untuk mentakrifkan "senarai abaikan." Tujuan utamanya ialah untuk mengecualikan fail yang tidak perlu ditambah ke kawalan versi. Fail atau laluan (yang boleh merangkumi wildcard) yang disenaraikan dalam fail ini tidak akan muncul dalam hasil `git status`, dan secara semula jadi tidak akan ditambah apabila melaksanakan `git add`.

Walau bagaimanapun, ini hanya terpakai kepada `Untracked files`. Fail yang sudah dijejak oleh Git (`Staged files`) tidak terjejas oleh fail `.gitignore`.

## Mencipta .gitignore Melalui GitHub

Jika anda pernah mencipta projek di GitHub, anda mungkin pernah menggunakan ciri ini. Apabila mencipta repositori baharu, anda boleh memilih senarai abaikan yang dipratentukan yang GitHub bantu anda sediakan. Senarai abaikan ini sebenarnya hanyalah fail bernama `.gitignore`, yang ditempatkan dalam direktori akar projek secara lalai.

Anda boleh memilih daripada pelbagai templat seperti:
- Node
- Python
- Java
- C#
- Visual Studio
- Dan banyak lagi

## Mencipta .gitignore Secara Manual

Hanya cipta fail bernama `.gitignore` dalam akar repositori anda:

```
# On Windows
echo node_modules/ > .gitignore

# On Linux/Mac
echo "node_modules/" > .gitignore
```

Atau ciptanya secara manual dengan editor teks.

## Corak Asas

### Abaikan Fail Tertentu

```
config.local.js
secrets.txt
```

### Abaikan Fail dengan Sambungan Tertentu

```
*.log
*.tmp
*.cache
```

### Abaikan Direktori

```
node_modules/
dist/
build/
```

Perhatikan garis miring di hujung untuk menunjukkan direktori.

### Abaikan Fail dalam Mana-mana Direktori

```
# Ignore all .log files in any directory
**/*.log
```

## Corak Lanjutan

### Penafian (Pengecualian)

Gunakan `!` untuk membuat pengecualian:

```
# Ignore all .log files
*.log

# But don't ignore important.log
!important.log
```

### Abaikan Fail dalam Direktori Tertentu Sahaja

```
# Ignore test.txt only in root directory
/test.txt

# Ignore test.txt in any subdirectory, but not root
*/test.txt
```

### Berbilang Sambungan

```
# Ignore multiple file types
*.{jpg,png,gif}
```

## .gitignore Global

Untuk corak yang anda ingin abaikan merentas semua repositori:

```
git config --global core.excludesfile ~/.gitignore_global
```

Kemudian cipta `~/.gitignore_global` dengan corak anda.

## Mengabaikan Fail yang Sudah Dijejak

Jika anda secara tidak sengaja membuat commit fail yang sepatutnya diabaikan:

```
# Remove from Git but keep the file
git rm --cached filename

# Remove directory from Git but keep it
git rm -r --cached directory/
```

Kemudian tambah corak ke `.gitignore` dan buat commit.

## Melihat Fail yang Diabaikan

Untuk melihat fail mana yang sedang diabaikan:

```
git status --ignored
```

## Menyemak Mengapa Fail Diabaikan

Untuk melihat corak mana yang menyebabkan fail diabaikan:

```
git check-ignore -v filename
```

## Fail Templat .gitignore

GitHub menyediakan fail templat .gitignore untuk pelbagai bahasa dan rangka kerja:

* https://github.com/github/gitignore

## Komen dalam .gitignore

Gunakan `#` untuk komen:

```
# This is a comment
*.log  # Inline comment
```

## Amalan Terbaik

1. **Commit .gitignore awal**: Tambahnya pada permulaan projek anda
2. **Jadilah spesifik**: Elakkan corak yang terlalu luas
3. **Dokumenkan sebabnya**: Gunakan komen untuk menerangkan corak yang tidak jelas
4. **Kekalkannya teratur**: Kumpulkan corak yang berkaitan bersama-sama
5. **Gunakan templat**: Mulakan dengan templat khusus bahasa
6. **Variasi setempat**: Gunakan `.git/info/exclude` untuk corak peribadi

## .gitignore Subdirektori

Anda boleh mempunyai fail `.gitignore` dalam subdirektori. Corak adalah relatif kepada lokasi fail `.gitignore`.

## Ringkasan Hari Ini

Fail `.gitignore` adalah penting untuk mengekalkan repositori anda bersih dan mengelakkan membuat commit fail yang tidak sepatutnya berada dalam kawalan versi secara tidak sengaja. Memahami sintaks corak dan amalan terbaik akan membantu anda mengekalkan repositori yang bersih dan profesional.

Izinkan saya menyusun semula perintah dan parameter Git yang dipelajari hari ini:

* git rm --cached
* git rm -r --cached
* git status --ignored
* git check-ignore
* git config core.excludesfile
