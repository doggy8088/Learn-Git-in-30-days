# Hari 10: Memahami Nama Mutlak Objek Git

Dalam proses kawalan versi Git, setiap versi mewakili objek commit. Oleh kerana cabang sering dicipta semasa kawalan versi, graf commit yang terhasil boleh menjadi agak kompleks. Oleh itu, cara mengenal pasti versi yang berbeza atau mencari versi tertentu dengan pantas untuk mendapatkan maklumat menjadi sangat penting. Artikel ini akan membantu anda memahami konsep nama objek dan kaedah penggunaan yang lazim digunakan dalam Git.

## Nama Mutlak Objek

Dalam Git, setiap objek mempunyai id yang dikira melalui hashing SHA1, dan id ini ialah apa yang dipanggil "nama mutlak." Jika objek ialah objek commit, maka ini ialah nama mutlak objek commit. Jadi selagi kita menjumpai nama mutlak objek commit, kita boleh mendapatkan versi itu pada bila-bila masa. Seperti yang ditunjukkan oleh anak panah dalam rajah berikut, ini ialah id objek commit yang kami peroleh melalui `git log`. Kita boleh mendapatkan maklumat terperinci tentang objek commit itu pada bila-bila masa.

![imej](figures/10/01.png)

Jika kita ingin melihat kandungan objek commit dalam rajah di atas, kita boleh menggunakan `git cat-file -p commitid` untuk mendapatkannya, seperti yang ditunjukkan dalam rajah berikut:

![imej](figures/10/02.png)

## Sintaks Pendek untuk Nama Mutlak Objek

Oleh kerana id objek Git ialah hasil hashing SHA1 kandungan, ia agak panjang (40 aksara). Apabila menentukan "nama mutlak" dalam Git, anda boleh menggunakan hanya beberapa aksara pertama sebagai gantinya, dengan minimum 4 aksara. Ini bermakna "nama mutlak" antara 4 hingga 40 aksara panjang semuanya boleh digunakan untuk mengenal pasti objek.

Contohnya, kita juga boleh lihat daripada rajah di atas bahawa kandungan objek commit ini mengandungi objek tree, yang juga mempunyai nama mutlak `07c1321be49815d53eb2413f0ad5286010ebb6cc`. Jadi saya juga boleh menggunakan `git cat-file -p treeid` sekali lagi untuk mendapatkan kandungan objek tree itu, seperti yang ditunjukkan dalam rajah berikut:

![imej](figures/10/03.png)

Kadangkala kita ingin mendapatkan rekod versi dan akan menggunakan perintah `git log`, yang juga akan mengeluarkan hasil perbandingan perubahan untuk setiap fail. Hasilnya akan menjadi sangat panjang. Pada masa ini, anda boleh menggunakan perintah `git log --pretty=oneline` untuk mendapatkan rekod sejarah yang lebih ringkas, dan anda juga boleh mendapatkan "nama mutlak" lengkap objek commit, seperti yang ditunjukkan dalam rajah berikut:

![imej](figures/10/04.png)

Satu lagi teknik yang lazim digunakan ialah mengeluarkan hanya sebahagian daripada "nama mutlak." Anda boleh melaksanakannya melalui perintah `git log --pretty=oneline --abbrev-commit`, seperti yang ditunjukkan dalam rajah berikut:

![imej](figures/10/05.png)

## Ringkasan Hari Ini

Di atas ialah penggunaan nama mutlak. Disebabkan ciri objek Git, anda boleh mengakses mana-mana objek dalam repositori Git melalui nama mutlak objek. Terdapat banyak lagi perintah git yang akan menggunakan nama mutlak. Biasa dengan konsep dan ungkapan ini, anda akan lebih menguasai objek Git.

Izinkan saya menyusun semula perintah dan parameter Git yang dipelajari hari ini:

* git log
* git cat-file -p [object_id]
* git log --pretty=oneline
* git log --pretty=oneline --abbrev-commit
