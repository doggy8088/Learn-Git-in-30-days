## Pengenalan

Dalam bidang pembangunan perisian, kawalan versi kod sumber ialah perkara yang sangat penting. Berbeza daripada sistem kawalan versi berpusat seperti Subversion atau TFVC (Team Foundation Version Control), Git ialah sistem kawalan versi teragih (DVCS; Distributed Version Control System) yang membawa banyak kelebihan kepada kawalan versi dan mengatasi kekurangan kawalan versi berpusat tradisional, seperti sokongan untuk operasi setempat, sandaran yang mudah, pencabangan dan cantuman yang berkuasa dan fleksibel, dan banyak lagi. Walau bagaimanapun, kerana kawalan versi Git amat berbeza daripada alat kawalan versi berpusat tradisional dari segi konsep kawalan versi mahupun penggunaan alat, ia mewujudkan keluk pembelajaran yang ketara. Sepanjang 30 hari yang akan datang, saya berharap dapat membantu anda memahami intipati kawalan versi Git dengan lengkap dan berkongsi pengalaman pembelajaran saya, bersama-sama masalah dan penyelesaian yang kami temui semasa syarikat kami beralih daripada Subversion kepada Git.

> **Nota Terjemahan:** Versi Bahasa Melayu ini ialah terjemahan daripada edisi Bahasa Inggeris bagi buku yang memenangi anugerah ini, dan ia mengekalkan konsep teras serta ketepatan teknikal edisi asal sambil menyesuaikan sebahagian kandungan untuk amalan Git moden dan pembaca antarabangsa.
